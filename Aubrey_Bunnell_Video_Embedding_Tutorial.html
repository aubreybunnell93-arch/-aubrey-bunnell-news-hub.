How to Embed a YouTube Video

By Aubrey Bunnell

This tutorial shows how to get the embed code from a YouTube video and place the video into an HTML webpage.

1

Open the YouTube video

Go to YouTube and open the video you want to add to your website. Make sure the video is appropriate and allows embedding.

2

Click Share

Under the video, click the Share button. This opens the sharing options for the video.

3

Select Embed

In the Share window, choose Embed. YouTube will display the HTML iframe code used to place the video on a webpage.

4

Copy the embed code

Click Copy next to the embed code. The code contains an iframe that connects your webpage to the hosted video.

5

Paste the code into your HTML

Open your HTML file and paste the copied iframe code inside the <body> section. Save the file and open the page in a browser to make sure the embedded video appears and plays correctly.
